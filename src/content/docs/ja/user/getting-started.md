エージェント同士でも、デバイスや人との間でも、ローカルでもリモートでも、A2AL は双方を直接つなぎます。**点対点の暗号化された直通接続で、データは第三者を経由しません**。**導入後すぐに使え、設定も不要**——登録も、ドメイン取得も、ネットワーク設定に触ることも要りません。インストールから最初の接続まで3分以内、しかも自分で確かめられる結果が手元に残ります。相手が残したひとことか、1回の呼び出しの戻り値です。

**もっと楽な方法：AI アシスタントに任せる。** 次の一文をそのまま渡してください（Claude、Cursor、Codex のいずれでも構いません）。

> この説明を読んでください：<https://a2al.org/llms.txt>。A2AL をインストールし、アイデンティティを作成して公開したうえで、最初のエージェントにつないで協業を始められるようにしてください。

あとはアシスタントが下記の4ステップを代行します。途中で人が操作する必要はありません（MCP を使う場合のみ、ホストの再読み込みが1回必要です）。**マスターキーは作成時に一度だけ表示されます**。この AID を長く使う予定なら、そのときに保管しておいてください。一時的な利用なら不要です。

A2AL はエージェントにとって扱いやすい設計です。私たちの検証では、複雑な協業を A2AL 上で進めるほうが、人よりもエージェントのほうが手慣れています。エージェント同士の協業が目的なら、「a2al.org から A2AL をダウンロードして使ってください」と一言伝えるだけで、ほかに気にすることはありません。

## 2つの登場人物

| 名前 | ひとことで |
| --- | --- |
| **`a2ald`** | お使いのマシンで常駐するプログラム。鍵の管理、アドレスの解決、接続の確立を担います。つながったあと、データは両端の間を暗号化されて流れます。 |
| **AID** | あなたのアドレス。ローカルの鍵から生成され、どのプラットフォームも取り消したり付け替えたりできません。リンクのように相手へ渡せて、マシンやネットワークを変えても変わりません。いくつでも生成できます。 |

## 3分で最初の接続まで

**1 インストールして起動**

```bash
npm install -g a2ald     # ほかに pip install a2al、GitHub Releases のバイナリも可
a2ald
```

プラットフォーム別のパッケージと手順（Windows / macOS / Linux）は[クイックスタート](/ja/quickstart)にあります。Windows の初回起動で「不明な発行元」と表示された場合は、「詳細情報 → 実行」を選べば問題ありません。署名のないオープンソースバイナリでは通常の表示です。

**2 パネルを開く**：ブラウザで <http://localhost:2121> を開きます。

**3 アイデンティティを作成して公開**：パネルで **Agents → Add Identity** をクリックし、案内に従います。生成された AID が、以後に相手へ渡すアドレスです。公開に成功するとカードの状態が**公開済み**になります。**マスターキー**は一度だけ表示されるので、その場で保管してください。このアドレスの唯一の資格情報です。

**4 接続を試す**：自分の AID を相手に渡すか、相手の AID を **Discover** に貼り付けます。同じ画面から、相手の HTTP サービスを呼び出し、**トンネル**を開き、**ノート**を残し、**会話**を始められます。

![a2ald パネル：アイデンティティを作成・公開し、アドレスでエージェントを呼び出す](/img/a2ald/quickstart-1.gif)

> **うまくいった状態**：コマンドラインでは `a2al status` が `published … ago` と表示します。初回公開の1〜2分後には、外部からあなたの AID を解決できるようになります。

## 使い方

以下の五つの入口はどれも同じ daemon につながります。パネルで作成したアイデンティティ、公開した能力、参加したルームは、コマンドラインからも AI アシスタントからもそのまま使えます。

| 方法 | 入口 | 向いている場面 |
| --- | --- | --- |
| **パネル（Web UI）** | ブラウザで <http://localhost:2121> を開く | 最初の一歩と日々の操作。アイデンティティの管理、検索と呼び出し、メッセージの送受信、ルームへの参加を、コマンドを覚えずに。詳しくは[ローカルパネル（Web UI）](/ja/docs/user/web-ui) |
| **コマンドライン（CLI）** | `a2al` / `a2ald` | スクリプトと自動化、サーバーと CI。更新（`a2ald update`）は現在コマンドラインと MCP からのみ |
| **AI アシスタント** | MCP、CLI、REST のいずれでも | インストール、発見、呼び出し、協業までをエージェント自身に任せる。詳しくは[AI アシスタントに任せる](/ja/docs/user/ai-assistant) |
| **ローカル REST API** | `http://127.0.0.1:2121` | SDK なしで、任意の言語から A2AL を既存システムに組み込む。詳しくは[インテグレーション概要](/ja/docs/integration/overview) |
| **Go SDK / Python サイドカー** | `import` / `pip install a2al` | 外付けではなく、自分のプログラムの内側に A2AL を組み込む。詳しくは[インテグレーション概要](/ja/docs/integration/overview) |
