`a2ald` 自带一个本机 Web 界面（面板）。启动 daemon 后，用浏览器打开 <http://localhost:2121> 即可使用——不需要安装额外软件，也不需要注册账号。

面板与命令行、MCP 是同一个 daemon 的不同界面：在这里创建的身份、发布的能力、加入的房间，其他界面都直接可用。

## 三个页签

| 页签 | 能做的事 |
| --- | --- |
| **Agents** | 创建身份（设置 **Agent URL**、可从主密钥恢复、也可用 Ethereum 身份）、导入与导出、发布与更新发布、编辑名片、访问控制（ACL）、探测连通性、收取便条、演示模式、删除身份；每个身份带一个会话气泡，用于一对一对话与房间（创建、查看、发言、传文件、退出） |
| **Discover** | 通过 AID 查询、按能力搜索、收藏与本地别名；对目标执行抓取（调用其 HTTP）、连通测试、建立隧道、发送便条；需要时填入加入口令 |
| **Node** | 节点与网络状态（peers、NAT 类型、对外观察地址、DHT 与 QUIC 状态）、配置读写（需重启才生效的字段会标注）、API Token、远程管理 |

## 几个常用操作

1. **创建身份并发布**：Agents → 添加新身份。主密钥只显示一次，请当场保存。
2. **调用别人**：Discover → 通过 AID 查询 → 选中目标 → 抓取或连通测试；也可以先按能力搜索，再从未知 AID 中挑选。
3. **让别人调用你**：把身份的 **Agent URL** 指向你的本机服务（即身份记录中的 `service_tcp`），然后发布。如需先验证效果，可用身份卡片上的**演示模式**：它临时提供一个可被其他节点发现并调用的演示服务，可随时停用。
4. **发消息**：Discover → 发送便条；或打开身份卡片上的会话气泡，进行一对一对话、创建房间或参与已有房间。
5. **访问不在身边的机器**：Discover → 选中目标 → **建立加密隧道**，将对方的端口映射到本机，再用本机客户端接入——SSH、远程桌面、数据库等均可。隧道为点对点加密直连，数据不经手第三方。
6. **在不同设备之间传文件**：在会话气泡的对话或房间里直接发送文件；两端不必处于同一网络，文档、图片、压缩包等任意类型均可。

## 只在本机可见

面板与管理 API 默认只监听 `127.0.0.1:2121`，因此不需要对外暴露端口，也不受 NAT 与防火墙影响。

需要从另一台机器管理这个节点时，用 **Node → 远程管理**：它经 A2AL 自身的加密通道授权指定 AID 访问管理面，而不是把 `2121` 开放到公网。相关取舍见[安全实践](/zh/docs/user/security-practices)。
